# Changelog

## 0.1.0 - 2026-08-27

Initial open-source package.

### Added

- Local-first project dashboard with SQLite storage.
- Command strip for owner, blockers, due tasks, review cards, open questions, and recent commits.
- Project board search and status filtering.
- Non-blocking review nudge.
- Project timeline, task Gantt view, artifact library, knowledge battle, question loop, and daily review.
- `/api/health` endpoint.
- Smoke test script.
- Local smoke test and GitHub Actions CI recipe.
- Open-source documentation, license, security policy, contribution guide, roadmap, and templates.
