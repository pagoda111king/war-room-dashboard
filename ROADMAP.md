# Roadmap

War Room Dashboard is a local-first command center. The roadmap is about making it safer, more portable, and more useful for serious AI-agent workflows.

## v0.2 - Data Portability

- JSON export for projects, tasks, artifacts, cards, and reviews.
- JSON import with validation and preview.
- Manual backup and restore commands.
- Example project packs.

## v0.3 - Workflow Depth

- Node/DAG view for complex projects.
- Checkpoint, rollback condition, entry criteria, and exit criteria fields.
- Reusable workflow templates.
- Better task dependencies.

## v0.4 - Agent Hooks

- Optional LLM provider adapters.
- Tool-call log and audit trail.
- Human confirmation gates for risky actions.
- Local prompt templates for project planning, review, and evidence capture.

## v0.5 - Private LAN Hardening

- Optional local authentication.
- Read-only demo mode.
- Safer write controls.
- Backup reminders.

## Long-Term Direction

- A personal AI operating room where human intent, agent execution, evidence, and reusable knowledge all become durable assets.
