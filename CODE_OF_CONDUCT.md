# Code of Conduct

War Room Dashboard aims to be a practical, respectful open-source project for people building better personal operating systems.

Please be kind, direct, and useful.

## Expected Behavior

- Be respectful of different experience levels.
- Give actionable feedback.
- Keep discussion focused on the project.
- Assume good intent, but clarify when something is confusing.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private user data.
- Spam, scams, or irrelevant promotion.
- Deliberately disruptive behavior.

## Reporting

If you see a problem, open a GitHub issue or contact the maintainer through the repository profile.
